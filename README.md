# 烛光来信 · Candle

送给一个人的生日礼物：从一封邀请开始，点亮蜡烛、许愿吹灭，再展开属于对方的生日来信。使用 Three.js 的实时火焰、暖金色排版和克制的庆祝动效。

## 预览

需要 Node.js。依赖已包含在 `vendor` 中，无须安装前端依赖。

```sh
npm start
```

打开 http://127.0.0.1:5173。可通过 `PORT` 环境变量修改端口。本地预览地址仅供这台电脑访问；要发给对方，需要将 `index.html`、`src/`、`vendor/` 放到支持 HTTPS 的静态网站托管服务上，保留目录结构。

## 写给对方

编辑 `src/gift.js`，修改收件人、署名、开场白和祝福正文。例如：

```js
export const gift = {
  recipient: '小满',
  sender: '你的名字',
  dedication: ['今天的微光，只为你而亮。', '慢慢来，这一刻属于你。'],
  message: [
    '这里写你们之间的一段回忆。',
    '这里写新的一岁，最想送给对方的话。',
  ],
};
```

当前文件里的称呼和祝福是示例。文字以纯文本显示；正文数组中的每一项是一段，也可以用 `\n` 换行。修改后刷新页面即可，保存的祝福图片也会使用同一份文案。

## 互动

- 点击主按钮、烛芯或火焰，完成点亮和吹灭；也支持 Enter / 空格，键盘聚焦按钮时保持原生操作。
- 声音默认关闭，右上角可以开启。许愿时可以选择「试试吹气」，授权后在本机检测声音，吹灭或切到后台后关闭麦克风。拒绝授权仍可点击按钮完成。
- 来信会一直保留，可以「珍藏这份祝福」下载 PNG，或「再许一次愿」重播。
- 手机使用纵向布局，长文案可滚动阅读。尊重系统的减少动态效果设置。
- WebGL 不可用或渲染上下文丢失时，自动使用二维蜡烛继续流程。二维版本使用按钮操作，不开启声音和麦克风。

## 项目与验证

`src/experience.js` 管理三幕内容与图片保存，`src/app.js` 负责启动与二维回退，`src/main.js` 保留 3D 场景、火焰、声音与吹气检测，`src/style.css` 管理布局与视觉样式。

```sh
npm test
```

服务器测试覆盖资源加载、异常路径、内部文件访问、目录穿越和符号链接绕过。静态服务仅开放页面、`src/` 和 `vendor/`；内部文件、隐藏文件和指向非公开文件的符号链接返回 403，非法 URL 编码返回 400。旧调试地址 `_raf_test.html` 跳转到主页面。

第三方库及许可保留在 `vendor/`。真实手机的 WebGL 性能、浏览器下载行为和麦克风灵敏度还需在目标设备上确认。
