开场邀请、烛光许愿、生日来信组成完整的收礼体验。姓名、署名与祝福集中配置。

## A 收礼体验

```flow LR
开场邀请 -> 点亮蜡烛: 点亮这一刻
点亮蜡烛 -> 安静许愿
安静许愿 -> 生日来信: 按钮、火焰或吹气
生日来信 -> 保存图片: 珍藏这份祝福
生日来信 --> 安静许愿: 再许一次愿
```

声音默认关闭。吹气由收礼人主动开启。生日来信持续显示。

## B 八项设计检查

| 维度 | 已落地的调整 |
| --- | --- |
| 字体 | 中文衬线标题与清晰的正文、按钮层级 |
| 留白 | 桌面两栏，手机纵向阅读，短屏压缩装饰空间 |
| 视觉层级 | 每一幕保留一个主操作，次要选项使用文字按钮 |
| 色彩 | 深暖色背景、奶油白正文、香槟金强调 |
| 动效 | 火焰、余烟、来信渐入与少量彩屑；支持减少动态效果 |
| 微交互 | 按钮反馈、麦克风状态、键盘焦点、保存与重播 |
| 响应式 | 场景按自身容器构图，长文案允许纵向滚动 |
| 专属感 | 称呼、开场白、正文和署名共同表达个人心意 |

这是一轮具体设计与实现检查，不代表获得设计奖项认证。

## C 怎样换成你们的故事

编辑项目中的 `src/gift.js`。

| 配置 | 用途 |
| --- | --- |
| recipient | 收礼人的称呼 |
| sender | 送礼人的署名 |
| dedication | 开场白，每一项占一行 |
| message | 来信正文，每一项是一段 |

当前文案是示例。建议把正文换成一段回忆、一份感谢和一个生日愿望。

运行 `npm start`，打开 http://127.0.0.1:5173。

本地地址供这台电脑预览。发给对方前，需要发布到 HTTPS 静态网站。

## E 验证与边界

5 项服务器回归测试通过。浏览器已验证点亮、吹灭、来信持续显示、重播与图片下载。
